## Section 1: Tribonacci พร้อม Unit Test

### Prompt

> [!NOTE]
> **Prompt**
>
> โย่ววว เก่งมากก ต่อไปเป็นข้อ 6 สุดท้ายละ<br>
> มันคือ function Tribonacci คล้าย Fibo แหละ แต่จะเป็นการบวก 3 ตัวแทน เช่น
>
> [1, 1, 1, 3, 5, 9]<br>
> [2, 3, 1, 6, 9, 16]
>
> จะให้เขียนฟังก์ชั่นรับ 2 ค่า<br>
> โดยค่าแรกจะเป็น [Int] โดยเป็นค่าเริ่มต้น จะมีตั้งแต่ 0-3 ตัว ตัวอย่างที่เป็นไปได้ดังนี้ [] , [5,2,0] , [1] , [3,4,1]
>
> ค่าที่สองเป็น non negative int บอกจำนวนที่ต้องการเช่น 0,5,3 โดยรวมค่าเริ่มต้นด้วย
>
> ตัวอย่างดังนี้
>
> f([1, 3, 5], 5) => [1, 3, 5, 9, 17]<br>
> f([2, 2, 2], 3) => [2, 2, 2]<br>
> f([10, 10, 10], 4) => [10, 10, 10, 30]
>
> อาจจะต้องดักเผื่อเคสที่ ค่าที่ 1,2 ไม่สอดคล้องกันด้วยนะ และอย่าลืม prompt.md , test

### Answer

> [!TIP]
> **Answer**
>
> #### 1. ตรวจตัวอย่างในโจทย์
>
> ตัวอย่าง `[2, 3, 1, 6, 9, 16]` ไม่ตรงกับกฎบวก 3 ตัวก่อนหน้า:
>
> | ตำแหน่ง | คำนวณ | ค่าที่ถูก | ค่าในโจทย์ |
> |---|---|---|---|
> | 4 | 2 + 3 + 1 | 6 | 6 |
> | 5 | 3 + 1 + 6 | **10** | 9 |
> | 6 | 1 + 6 + 10 | **17** | 16 |
>
> ลำดับที่ถูกคือ `[2, 3, 1, 6, 10, 17]` และใช้ค่านี้ใน test ตัวอย่างอื่นทั้งหมดถูกต้อง
>
> #### 2. กฎเมื่อค่าที่ 1 และค่าที่ 2 ไม่สอดคล้องกัน
>
> | กรณี | ตัวอย่าง | ผลลัพธ์ |
> |---|---|---|
> | `n = 0` | `([3, 4, 1], 0)` | `[]` |
> | `n` น้อยกว่าจำนวนค่าเริ่มต้น | `([5, 2, 0], 2)` | `[5, 2]` ตัดเหลือ `n` ตัวแรก |
> | ค่าเริ่มต้น 1 ตัว | `([1], 5)` | `[1, 1, 2, 4, 7]` |
> | ค่าเริ่มต้น 2 ตัว | `([3, 4], 5)` | `[3, 4, 7, 14, 25]` |
> | ค่าเริ่มต้นว่าง และ `n > 0` | `([], 5)` | throw `RangeError` |
> | ค่าเริ่มต้นเกิน 3 ตัว | `([1, 2, 3, 4], 5)` | throw `RangeError` |
>
> **ค่าเริ่มต้น 1 หรือ 2 ตัว** โจทย์ไม่ได้กำหนด เลือกใช้กฎ "ค่าถัดไป = ผลรวมของค่าก่อนหน้าที่มีอยู่ (ไม่เกิน 3 ตัวล่าสุด)" เมื่อมีครบ 3 ตัวแล้วจะเป็น Tribonacci ปกติ อีกทางเลือกคือเติม 0 ข้างหน้า (`[1]` เป็น `[0, 0, 1]`) ซึ่งให้ผลต่างกัน จึงระบุไว้ใน remark
>
> **ค่าเริ่มต้นว่าง และ `n > 0`** ไม่มีค่าให้บวก จึง throw แทนการเดาค่า
>
> #### 3. Validation อื่น (throw `RangeError`)
>
> - ค่าเริ่มต้นที่ไม่ใช่จำนวนเต็ม (`0.5`, `NaN`)
> - `n` ที่ไม่ใช่จำนวนเต็มที่ไม่ติดลบ (`-1`, `2.5`, `NaN`, `Infinity`)
> - ค่าที่คำนวณได้เกิน `Number.MAX_SAFE_INTEGER` ตัวอย่าง `[1, 1, 1]` สร้างได้สูงสุด 62 ตัว ตัวที่ 63 จะ throw
>
> #### 4. Implementation (`question6/tribonacci.ts`)
>
> ```ts
> const SIZE = 3
>
> export function tribonacci(signature: number[], n: number): number[] {
>   // validation (ดูข้อ 2 และ 3)
>
>   const result = signature.slice(0, n)
>   if (result.length === n) {
>     return result
>   }
>
>   if (result.length === 0) {
>     throw new RangeError(`Signature is empty, so it cannot make ${n} values`)
>   }
>
>   while (result.length < n) {
>     const next = result.slice(-SIZE).reduce((sum, value) => sum + value, 0)
>     if (!Number.isSafeInteger(next)) {
>       throw new RangeError(`Value ${result.length + 1} is bigger than Number.MAX_SAFE_INTEGER`)
>     }
>     result.push(next)
>   }
>   return result
> }
> ```
>
> - `signature.slice(0, n)` ทำ 2 อย่างในครั้งเดียว: copy array (ไม่แก้ input) และตัดเหลือ `n` ตัวเมื่อ `n` น้อยกว่าจำนวนค่าเริ่มต้น
> - `result.slice(-3)` เอา 3 ตัวล่าสุด ถ้ามีน้อยกว่า 3 ตัวจะได้เท่าที่มี จึงรองรับค่าเริ่มต้น 1 หรือ 2 ตัวโดยไม่ต้องแยก code
>
> #### 5. Remark: เคสที่ไม่ได้ Support
>
> 1. **ค่าเกิน `Number.MAX_SAFE_INTEGER`:** ไม่รองรับ `BigInt`
> 2. **ค่าเริ่มต้นเป็นทศนิยม:** `0.5`
> 3. **กฎอื่นสำหรับค่าเริ่มต้นไม่ครบ 3 ตัว:** เช่น เติม 0 ข้างหน้า
> 4. **`n` ที่ใหญ่มาก:** เก็บทั้ง array ไว้ใน memory ไม่มี lazy generator
>
> #### 6. Unit Test (`question6/tribonacci.test.ts`)
>
> ใช้ `node:test` + `node:assert/strict` เหมือนข้อก่อน มี 24 tests ใน 6 suites:
>
> 1. **ตัวอย่างจากโจทย์:** 3 ตัวอย่าง `f(...)` และลำดับ `[1, 1, 1, 3, 5, 9]`, `[2, 3, 1, 6, 10, 17]`
> 2. **ค่าเริ่มต้น 3 ตัว:** มี 0, เป็น 0 ทั้งหมด, ติดลบ
> 3. **ค่าที่ 1 และ 2 ไม่สอดคล้องกัน:** ทุกกรณีในตารางข้อ 2
> 4. **Input ไม่ถูกต้อง:** `n` ติดลบ ทศนิยม `NaN` `Infinity`, ค่าเริ่มต้นไม่ใช่จำนวนเต็ม, ค่าเกิน `Number.MAX_SAFE_INTEGER`
> 5. **อื่น ๆ:** ไม่แก้ input, คืน array ใหม่, ความยาวผลลัพธ์เท่ากับ `n` เสมอ (`n` = 0 ถึง 20), ทุกตัวเท่ากับผลรวม 3 ตัวก่อนหน้า
> 6. **ขอบเขต safe integer:** `[1, 1, 1]` ได้ 62 ตัว และ 63 ตัว throw
>
